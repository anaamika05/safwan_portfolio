# Safwan Kalliparambil – Portfolio

Static site: HTML5, CSS3, vanilla JavaScript. No build step, no frameworks.

## Run locally
1. Open the `safwan-portfolio` folder in VS Code.
2. Double-click `index.html`, or right-click it in VS Code and choose **Open with Live Server** (optional extension).

Fonts (Cormorant Garamond, Inter) load from Google Fonts; offline it falls back to Georgia / system sans.

## Before you share it
1. **CV** – put the PDF at `assets/documents/Safwan_Kalliparambil_CV.pdf` (exact name). The Download CV buttons link to that file; until it exists, the download will fail.
2. **Email & phone** – the Contact section in `index.html` includes clickable email and phone links.
3. **Certifications** – the Education section includes the listed certification names.

## Save as PDF
Click **Save as PDF** in the footer (or press Ctrl/Cmd+P) and choose "Save as PDF". The print stylesheet at the end of `style.css` hides navigation and buttons.
